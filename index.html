Colar do Claude

Cole um bloco JSON gerado numa conversa comigo para adicionar tarefas, hábitos e projetos de uma vez, sem digitar.

Números

Zona de risco

Apaga tudo deste navegador. Sem volta, a não ser que exista um backup exportado.

Formato do bloco "Colar do Claude"
{
  "projects": [ { "name": "Concurso", "color": "roxo" } ],
  "tasks": [
    { "title": "Revisar edital", "due": "2026-08-10", "project": "Concurso",
      "priority": "alta", "tags": ["susepe"], "notes": "" }
  ],
  "habits": [
    { "name": "Academia", "emoji": "🏋️", "color": "verde", "days": ["seg","qua","sex"] },
    { "name": "Leitura", "emoji": "📖", "color": "azul", "days": "diario" }
  ],
  "people": [
    { "name": "Fulano de Tal", "phone": "51 99999-0000", "email": "",
      "birthday": "1990-08-15", "tags": ["mp"], "notes": "Colega da 1ª PJ" }
  ],
  "notes": [
    { "title": "Prazos da LIA", "body": "Prescrição: 8 anos…", "tags": ["direito"] }
  ],
  "places": [
    { "name": "Sabor do Sul", "kind": "restaurante", "city": "São Leopoldo",
      "status": "quero", "notes": "indicação da Duda" }
  ],
  "routines": [
    { "name": "Academia", "days": ["ter","qui"], "start": "18:30", "end": "19:30", "color": "verde" }
  ],
  "reminders": [
    { "title": "Estagiária nova começa", "date": "2026-08-07", "notes": "Preparar a mesa" }
  ]
}

Cores aceitas: azul, verde, ambar, vermelho, roxo, ciano, rosa, grafite. Prioridade: alta, media, baixa ou nenhuma. Dias: "diario" ou lista com dom, seg, ter, qua, qui, sex, sab. Tipos de lugar: viagem, restaurante, bar, passeio, outro. Status de lugar: quero ou fui.

Schema

Todas as coleções do banco (tarefas, projetos, hábitos, tempo, pessoas, contatos, rotina, notas e lugares) têm interface. O backup exporta tudo num único arquivo .json.
